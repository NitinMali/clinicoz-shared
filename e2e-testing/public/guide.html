Action Types

Each instruction must start with an action verb. One action per line.

Click

Click [data-testid="save-button"]
Click button[type="submit"]
Click #login-btn
Click .btn-primary

Type / Fill

Types text into an input. Text must be in quotes.

Type "kaveri@test.com" in input#email
Type "Pass@1234" in input[data-testid="password-input"]
Type "Nitin Mali" in input[placeholder="Search by patient name"]

Clear

Clear input#govId
Clear [data-testid="government-id-input"]

Select (PrimeReact Dropdown)

Opens the dropdown and clicks the option. Works with PrimeReact p-dropdown.

Select "Male" in #gender
Select "Active" in [data-testid="status-dropdown"]
Select "1" in select[data-testid="month-dropdown"]

Selector Formats

Direct selectors bypass the AI — they're faster, free, and 100% reliable.

TypeFormatExample
data-testid (best)[data-testid="name"]Click [data-testid="save-btn"]
ID#idType "hello" in #email
Class.classClick .btn-primary
Tag + attributetag[attr="val"]Click button[type="submit"]
Placeholderinput[placeholder="..."]Type "text" in input[placeholder="Search"]
How to find selectors: Right-click an element in Chrome → Inspect → look for data-testid, id, placeholder, or class attributes.

Wait & Verify (No AI needed)

These instructions are handled directly — no AI call, no cost.

Wait for navigation

Wait for page to redirect to /visits
Wait for page to redirect to /patients/
Wait for page to navigate to /dashboard

Wait for page load

Wait for page to load

Wait for sidebar/dialog

Wait for sidebar to appear
Wait for dialog to open
Wait for modal to appear

Wait for toast/notification

Wait for toast message to appear
Wait for success message to appear

Wait fixed time

Wait 2 seconds
Wait 5 seconds

Verify

Verify the page URL contains /visits

Dynamic Values (Utilities)

Generate random data for test isolation.

InstructionExample Output
Type random name in ..."Test David Kumar"
Type random mobile in ..."0000012345"
Type random email in ..."test.a8k3m2@test.com"
Type current date and time in ..."5/24/2026, 10:30:00 PM"
Type current date in ..."5/24/2026"
Type random number(1, 100) in ..."42"

Random names are always prefixed with "Test" for easy identification.

Auth Settings (Skip Login)

Configure once in the Auth Settings section on the dashboard:

  1. Enter Login URL, Email, Password
  2. Click "Save Auth"
  3. Set your test's Target URL directly to the page you want to test
Don't mix! If Auth Settings are configured, don't include login steps in your instructions. The system auto-logs-in before navigating to the target URL. 
Target URL: https://admin.clinicoz.com/cms/patients/.../profile

1. Click [data-testid="edit-other-details"]
2. Wait for sidebar to appear
3. Clear [data-testid="gov-id-input"]
4. Type current date and time in [data-testid="gov-id-input"]
5. Click [data-testid="save-btn"]
6. Wait for toast message to appear

Tips & Troubleshooting

ProblemSolution
AI can't find elementUse direct selector: [data-testid="..."]
Timeout on selectorCheck selector in browser DevTools (right-click → Inspect)
Fill instead of clickMake sure instruction starts with "Click" not "Type"
Navigation timeoutUse partial path like /visits not full URL
Stale cached selectorClick "Clear Cache" button in dashboard header
Double loginUse Auth Settings OR login steps, not both
Can't reach localhost from DockerUse http://host.docker.internal:PORT
Screenshot not showingClick "Details" button on the failed test case
Best practice: Ask developers to add data-testid attributes to all interactive elements. This makes tests bulletproof — no AI guessing needed.
